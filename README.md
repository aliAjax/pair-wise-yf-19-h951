# 植物标本馆入库工作台

把纸单登记的压制标本搬到一个前端工作台：录入采集信息，按「待压制 → 待鉴定 → 已入库」三段流转，自动分配馆藏藏位，所有数据保存在浏览器本地（localStorage）。

## 功能

- **标本登记**：采集号、物种、采集地点、海拔、生境、采集人；新单一律进入待压制队列。
- **重复采集号**：登记或修改时若采集号已存在，保留原记录、拒绝写入，并在右下角提示，可一键打开原记录核对。
- **三段流转**：
  - 未压制不能鉴定（鉴定按钮禁用，需先标记已压制）；
  - 未鉴定不能上柜（柜位选择禁用，需先完成鉴定并写明物种）；
  - 柜位满时拒绝分配，柜位面板显示「已满」和逐格占用情况。
- **入库队列**：可按队列状态（待压制 / 待鉴定 / 已入库）和鉴定状态（未压制 / 未鉴定 / 已鉴定）双重筛选，行内可直接流转、选柜上柜。
- **馆藏柜位记录**：按柜展示容量、占用数和每格标本，点击格位打开详情；已满的柜高亮。
- **采集地点信息卡**：按地点汇总标本份数、各阶段数量、占用柜位，列出当地每份标本，点击打开详情。
- **标本详情**：列表、柜位格、地点卡三处都可打开；可编辑全部字段、执行流转、分配或调整柜位，修改后队列 / 地点卡 / 柜位同步更新，并写入流转记录。
- **本地存储**：数据存于 `localStorage`（键名 `herbarium-workbench-v1`），可在顶栏一键恢复演示数据。
