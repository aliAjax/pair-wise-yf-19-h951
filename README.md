# hxyfront-62007 植物标本馆入库

源提示词编号：9

植物标本馆压制标本入库工作台。工作人员可录入采集号、物种名称、采集地点、海拔、生境描述、采集人，标本按「待压制 → 待鉴定 → 已入库」流转，数据保存在浏览器本地（localStorage）。

## 功能

- **标本录入**：采集号、物种、地点、海拔、生境、采集人；重复采集号保留原记录并提示，可直接查看原记录
- **入库队列**：按鉴定状态筛选（全部 / 待压制 / 待鉴定 / 已入库），行内快捷操作
- **流转规则**：未压制不能鉴定，未鉴定不能上柜；鉴定入柜时分配柜位格号（如 A-01-03）
- **柜位管理**：柜位占用看板；柜满时拒绝分配并显示占用（n/容量），已入库标本可调柜
- **采集地点卡**：按地点汇总标本、海拔范围与所占柜位
- **详情弹窗**：队列、地点卡、柜位看板均可打开；修改字段、推进流转后全页面同步更新
- **本地持久化**：localStorage 存储，多标签页自动同步
